# 智慧班級分組系統 V2.2

以瀏覽器操作的班級分組與座位規劃工具，支援學生名單管理、出席名單篩選、組別容量設定、分組限制與結果微調。

## 使用方式

直接以瀏覽器開啟 `index.html`。名單與設定會儲存在目前瀏覽器的本機儲存空間；需要跨裝置保存時，請使用頁面中的 JSON 備份與讀取功能。

## V2.2 更新

- 等本機資料載入完成後才啟動自動儲存，避免空白初始狀態覆蓋既有名單。
- 出席名單支援換行、逗號、頓號、分號分隔，並可用座號或姓名比對；沒有比對到學生時不會改用全班名單。
- JSON 備份讀取前會檢查名單、座位數與重複座號。
- 加強組別規則輸入檢查，偵測指定組別與同組／分組條件的直接矛盾。
- 分組時優先平衡各組男女比例：4 人組以 2 男 2 女為目標；5 人組以 3 男 2 女或 3 女 2 男為目標。若班級男女總數或指定組別規則造成限制，系統會盡量拉近比例。
- 手動換位會遵守已指定的組別。
- 組數多於學生人數時，不會自動產生零座位組別。
